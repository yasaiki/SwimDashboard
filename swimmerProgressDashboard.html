Goal & Standards JSON Reference
Edit the <script type="application/json" id="dashboardConfig"> block in this file. Goals use: swimmer key → stroke → distance → target seconds → label. Age-group standards use: gender ("F"/"M") → stroke → distance → age-bracket key → level → cutoff seconds, plus top-level ageBrackets (min/max age per bracket key) and standardsLevels (ordered easiest to hardest). Each swimmer's gender field (in the swimmerData object above) determines which half of the standards table they're compared against.
