Goal & Standards JSON Reference
Edit the <script type="application/json" id="dashboardConfig"> block in this file. Goals use: swimmer key → stroke → distance → target seconds → label. USA Swimming standards are stored under usaStandards.courses → course (SCY/SCM/LCM) → gender (F/M) → age bracket → stroke → distance → level → cutoff seconds. The dashboard currently applies SCY to yard results and SCM to meter results. Each swimmer's currentAge and gender determine the reference age group.
